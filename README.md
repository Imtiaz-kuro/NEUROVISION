# 🧠 NEUROVISION AI
### AI-Powered Brain MRI Segmentation & 3D Visualization

An experimental AI project exploring brain MRI analysis, automated tumor segmentation, volumetric analysis, and interactive 3D visualization.

## 🚀 Features

- **3D MRI Visualization:** Explore brain MRI scans in three dimensions.
- **Tumor Segmentation:** AI-assisted segmentation of tumor regions.
- **Multi-Planar Views:** Analyze MRI slices across multiple planes.
- **Volumetric Analysis:** Estimate and visualize segmented tumor volumes.
- **Interactive Interface:** Explore reconstructed MRI regions in 3D.

## 🛠️ Technologies

- Python
- PyTorch
- MONAI
- FastAPI
- Three.js
- JavaScript

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/neurovision-ai.git
cd neurovision-ai
```

Install Python dependencies:

```bash
pip install -r requirements.txt
```

Start the backend using the appropriate entry point:

```bash
uvicorn backend.main:app --reload
```

Follow the frontend setup instructions in the frontend directory.

## 🎯 Project Objective

To explore the application of Artificial Intelligence, deep learning, and computer vision in medical imaging through brain MRI segmentation and interactive visualization.

## ⚠️ Disclaimer

This project is experimental and intended for educational and research demonstration purposes only. It is not clinically validated and must not be used for medical diagnosis or treatment decisions.
